# Quy tắc lập trình cho chế độ Code

## Các quy tắc lập trình không hiển nhiên

1. **Sử dụng camelCase cho biến và hàm trong TypeScript**, PascalCase cho class và interface
2. **Sử dụng camelCase cho biến và hàm trong Dart**, PascalCase cho class và enum, snake_case cho tên file
3. **Sử dụng UPPER CASE cho từ khóa SQL**, lowercase cho tên bảng và cột
4. **Tránh sử dụng kiểu `any` trong TypeScript** trừ khi absolutely necessary
5. **Sử dụng type definitions cho tất cả biến và hàm** để tăng tính an toàn của code
6. **Cấu hình Next.js 14 với App Router và static export** cho việc triển khai lên GitHub Pages
7. **Sử dụng Provider pattern cho quản lý state** trong ứng dụng Flutter
8. **Tùy chỉnh theme Tailwind CSS** với bảng màu đặc trưng của thương hiệu
9. **Tích hợp Google Analytics** với gtag
10. **Lazy loading cho hình ảnh** sử dụng react-lazy-load-image-component
11. **Cơ chế xác thực JWT với refresh token**
